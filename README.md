# Design Library

E-Mail-Module, LP-Module und Design-Tokens in einer gemeinsamen Library.

Öffentliche URL: https://scout24-creative-ops.github.io/design-library/

Dieses Repository ist die generierte öffentliche Ausgabe. Änderungen werden in
`scout24-creative-ops/design-system` entwickelt. Die Modulquellen bleiben
`scout24-creative-ops/email-builder` und `scout24-creative-ops/lp-builder`.
`manifest.json` dokumentiert die verwendeten Eingabedateien mit SHA-256.

GitHub Pages: Branch `main`, Verzeichnis `/ (root)`. Kein Build-Schritt nötig.
Vorhandene Runtime-Distributionen sind unabhängig von dieser Library.
